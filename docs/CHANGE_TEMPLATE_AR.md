# قالب إلزامي لإدخال سجل جديد في `CHANGELOG.md`

> انسخ القالب عند **كل** تعديل أو عملية على الخادم، واملأ الحقول. لا تنقل أسرارًا أو بيانات عملاء.

```markdown
## CHG-YYYYMMDD-NN — عنوان واضح
- **التاريخ/التوقيت:** YYYY-MM-DD HH:MM (حدد المنطقة الزمنية)؛ **المنفذ:** إنسان / AI؛ **الحالة:** نُفذ محليًا / نُشر على AWS / مؤكد / معلّق.
- **الهدف والسبب:** لماذا تم هذا العمل؟
- **النطاق:** ملفات تغيرت أو مكونات AWS/GitHub/Cloudflare تأثرت.
- **الخطوات/الأوامر:** أوامر قصيرة أو وصف عملي لا يحتوي أسرارًا.
- **الدليل والاختبار:** مخرجات فعلية أو وصف تدقيق، وما الذي لم يُختبر.
- **المخاطر:** أثر محتمل على الأمان والبيانات/العملاء/الموقع.
- **الرجوع/النسخ:** كيف نعود للحالة السابقة بأمان.
- **الخطوة التالية:** إجراء واحد مطلوب، أو «لا يوجد».
- **المراجع:** مسار وثيقة أو commit/PR/issue إن توفر.
```

**التعليمات:** أضف الإدخالات الحديثة في أعلى `CHANGELOG.md` تحت قسم «التغييرات»؛ لا تحذف التاريخ السابق. عند فشل عملية، سجّل الفشل وخطوة الاستعادة بدل إخفائه.
