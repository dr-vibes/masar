## نقاط لا يجوز ادعاء إنجازها
- لا توجد قاعدة بيانات آمنة، ولا مستخدمون داخل التطبيق، ولا نقل لبيانات من localStorage إلى قاعدة خارجية.
- لا يوجد اختبار إند-تو-إند أو فحص اختراق أو مراجعة مطابقة مصرفية رسمية.
- نجاح `apt-get upgrade -y` النهائي ليس مثبتًا بعد بمخرجات تحقق.
- إعداد GitHub CI أو ربط GitHub بالإصدار المنشور لم يثبت؛ لا تخلط إعدادات `netlify.toml` مع نشر AWS الحالي.
- لقطة EBS لا تكافئ نسخة بيانات تطبيق دورية أو تجربة استعادة مؤكدة.
